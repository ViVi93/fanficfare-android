# FanFicFare Android – Hermes Skill Triggers

Quick copy-paste phrases to activate project skills.

## Upstream port
Use when syncing upstream FanFicFare source changes.
- `port upstream fanficfare changes`
- `update fanficfare from source`
- `sync fanficfare upstream`
- `fanficfare repo update`

## Regression check
Use before merging or releasing Android changes.
- `regression check fanficfare`
- `before merge fanficfare`
- `verify fanficfare build`
- `fanficfare release checks`
